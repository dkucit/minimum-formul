# Минимум формул

Веб-тренажёр по биохимическим формулам: узнать вещество по структурной формуле.
Это перенос базы вопросов «минимум_формул» из старой DOS-программы тестирования (NEP_MAIN.EXE под DOSBox) на обычный сайт, который работает с любого устройства.

**Открыть:** https://dkucit.github.io/minimum-formul/

## Режимы

- **Тренировка** — ответ проверяется сразу, ошибки запоминаются для повторения.
- **Экзамен** — случайные вопросы (10/20/30/50/все), 30 секунд на вопрос, итог и зачёт в конце.
- **Все формулы** — каталог с поиском; ответы можно скрыть и учить как карточки.

Прогресс (ошибки, лучший результат) хранится только в браузере на вашем устройстве.

## Файлы

- `data.js` — 204 вопроса: `img` — номер картинки, `a` — варианты, `c` — индекс правильного ответа.
- `img/` — формулы, извлечённые из `BM.TST`.
